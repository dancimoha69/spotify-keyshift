# Как устроен Key Shift для Spotify на Windows

Key Shift встраивает кнопку управления в локальный интерфейс Spotify и запускает отдельный Windows-компаньон для обработки звука. Компаньон захватывает только аудиопоток процесса Spotify, меняет высоту тона с сохранением темпа и отправляет обработанный звук на то же устройство вывода.

Spotify должен быть запущен, а музыка — играть. Отключи эксклюзивный режим аудиоустройства, если он включён: в этом режиме Windows может не дать захватить поток Spotify.

Установщик сохраняет исходный файл интерфейса перед изменением. Удаление Key Shift возвращает исходную копию, если файл Spotify не менялся после установки. Обновление Spotify может заменить интерфейс и убрать кнопку; в таком случае повторно запусти установщик Key Shift.
